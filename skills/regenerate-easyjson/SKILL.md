# Regenerate EasyJSON Code for DB Models

`models_easyjson.go` in `internal/repository/database/models` is generated by
`easyjson`. Never hand-edit it — regenerate after changing any model struct in
that package.

## Command

```sh
make generate_easyjson
```

This runs (see `Makefile`):

```sh
easyjson -snake_case -all -pkg internal/repository/database/models/
```

## When to run

- After adding, removing, renaming, or retyping a field on any struct in
  `internal/repository/database/models` that is serialized to/from JSON.
- When `models_easyjson.go` is out of sync with the structs (build or test
  failures referencing easyjson Marshal/Unmarshal methods).

## Notes

- Requires `easyjson` to be installed and on `PATH`
  (`go install github.com/mailru/easyjson/...@latest`).
- `-all` regenerates marshalers for every type in the package; `-snake_case`
  matches the JSON field naming used across the codebase.
- Adding a non-serialized field (e.g. a GORM association pointer with no `json`
  tag) usually still compiles without regenerating, but regenerate anyway to keep
  the generated file authoritative.
- After regenerating, run `go build ./...` and the models tests to confirm.
